# nicheLine Messaging App Dashboard

A comprehensive, premium-styled dashboard for managing users, subscriptions, and application settings for the nicheLine Messaging App. Built with React, Vite, and Ant Design.

## 🚀 Features

### 📊 Dashboard
- **Overview**: Real-time statistics for Total Users, Active Subscriptions, and Revenue.
- **Visualizations**: Interactive charts for user growth and engagement.
- **Recent Activities**: Quick view of recently joined users.

### 👥 User Management
- **User Directory**: Searchable and filterable list of all registered users.
- **Actions**: View detailed profiles, edit user information, and block/unblock users.
- **Premium UI**: Dark-themed tables with rich data display (Avatar, Role, Status).

### 💳 Subscription Management
- **Plans**: Create, Edit, and Delete subscription packages (Free, 1 Year, 3 Year, etc.).
- **Subscribers**: Dedicated view to manage active subscribers and their plan details.
- **Responsiveness**: Fully mobile-responsive tables with horizontal scrolling logic.

### 🔐 Authentication & Security
- **Complete Flow**: Sign In, Forgot Password, Verification Code, and Reset Password pages.
- **Design**: Unified premium dark theme across all authentication screens.

### ⚙️ Settings & Profile
- **Profile Management**: Update personal details and change passwords securely.
- **Static Pages**: CMS-like editors for Terms & Conditions, Privacy Policy, and About Us.
- **Theming**: Consistent dark card layouts with teal accents.
